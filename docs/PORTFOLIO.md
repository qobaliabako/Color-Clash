## Upload the project to GitHub

1. Extract `color-clash-source-v3.zip`.
2. Create a GitHub repository named `color-clash`.
3. Add the **contents** of the extracted `color-clash-source-v3` folder to the repository root. The root should contain `README.md`, `package.json`, `app/`, `lib/`, and the other source files; do not upload only the ZIP.
4. Include dotfiles such as `.gitignore`, `.env.example`, `.npmrc`, and `.openai/hosting.json`. GitHub Desktop is convenient because file-picker uploads can omit hidden files.
5. Commit and push. Set the repository's About description to the text above and the website link to the live project URL below.
6. Add the resulting GitHub repository URL alongside the live project URL on your CV or portfolio.

The ZIP contains code and synthetic fixtures only. Keep research results and personal environment files outside the public repository.
